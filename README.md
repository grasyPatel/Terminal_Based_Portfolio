# 🖥️ Terminal-Style Portfolio

Welcome to my **interactive terminal-style portfolio**!  
A web-based command-line interface where you can type commands like `help`, `projects`, `experience`, `contact`, and more — just like a real terminal!

> 🚀 Built using modern frontend tools to provide a unique developer experience.
---
 [![Live Demo](https://img.shields.io/badge/Demo-Live-blue?style=for-the-badge)](https://terminal-portfolio-i1rl.onrender.com/)


---

## ✨ Features

- ⌨️ Terminal-like UI/UX (typing commands to explore)
- 📁 Project showcase with descriptions and GitHub links
- 💼 Work experience rendered on command
- 📫 Contact details and social links
- ⚙️ Styled with Tailwind CSS for clean visuals
- 🧠 Fast and responsive with React.js

---

## 🛠 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Routing / Logic:** Command parser, React hooks
- **Deployment:** Vercel
---

## 🧪 Commands You Can Try

| Command       | Description                          |
|---------------|--------------------------------------|
| `help`        | Show all available commands          |
| `projects`    | List my personal and major projects  |
| `experience`  | Display work experience              |
| `skills`      | Show technical skills with ratings   |
| `contact`     | Show social links and contact info   |
| `clear`       | Clear the terminal screen            |

many more....
